# Organizador De Tarefas

## Tarefa 1.1 – Proposta de Aplicação

### Problema que a aplicação resolve
A aplicação Organizadot De Tarefas foi criada para ajudar estudantes universitários a organizarem atividades acadêmicas e acompanharem o andamento das disciplinas. Muitos alunos possuem dificuldade em controlar prazos, tarefas pendentes e atividades concluídas durante o semestre.

### Usuários principais
Os principais usuários da aplicação são estudantes universitários que desejam gerenciar tarefas relacionadas às disciplinas da faculdade.

### Entidades centrais
- Disciplina
- Atividade
